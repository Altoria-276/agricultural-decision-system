安装代码
1. 安装 Python 3.10
2. 在代码根目录，创建本地虚拟环境
	python -m venv ./.venv
3. 激活虚拟环境
	./.venv/Scripts/activate
4. 更新 pip
	python.exe -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple
4. 安装对应 Python 包
	pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
5. 运行 main.py
	python ./main.py
6. 通过浏览器打开
	127.0.0.1:7860

运行代码
	运行 run_script.bat
	浏览器输入 http://127.0.0.1:7860
